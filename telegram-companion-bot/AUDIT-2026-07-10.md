### Deepseek claims rejected after verification

- **"Stray module-level code → NameError on import"** — false: the block is
  *unreachable dead code inside a function* (see fix 13); the file imports fine.
- **"`perform_self_update` backs up the new file, rollback impossible"** — false:
  it copies the OLD bot.py to `bot.py.bak` *before* the swap. Rollback works.
- **"jokes.json concurrent-write corruption"** — false: single caller, on the event
  loop, no await inside. (Real lesser gap: the write isn't atomic — Track 4.)
- **"Backup references user_notes.txt which moved into state.json"** — false premise:
  it's a live flat file and correctly backed up.
- **"user_notes.txt injected into every chat's prompt"** — by design for single-owner
  bots; the group path already excludes it.
