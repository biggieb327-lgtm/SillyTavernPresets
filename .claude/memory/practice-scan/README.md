# practice-scan

Weekly output of the `practice-scan-weekly` Routine (see
`.claude/operating/routines.md`). One file per firing, named for the date it ran:
`<YYYY-MM-DD>.md`.

Each file holds at most 5 ideas drawn from the two Substack publications the
Routine owns, every one tagged `[fleet memory]` or `[operating]`, carrying its
source URL and an exact quoted line.

**Everything here is a proposal.** Nothing in this directory has been applied,
reviewed, or agreed to. The Routine is forbidden from editing code, cards,
presets, hooks, skills, agents, or evals — it writes to this directory on the
branch `claude/practice-scan` and nowhere else.

A quiet week produces no file at all: the Routine pushes nothing and reports
"practice-scan: nothing this week". An empty directory for a given week is the
expected result of a quiet week, not a failed run.
